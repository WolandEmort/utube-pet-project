# `useApi`: Tech Doc
 
> Ретроспективний опис: так я описав би цей хук за підходом design-first.
 
**Що:** єдина функція `request(endpoint, options)` для запитів до бекенду. Повертає дані сервера або кидає `Error` із повідомленням.
 
**Контракт:** токен іде в заголовку `Authorization: Bearer <token>`; помилки сервера мають вигляд `{ "error": "..." }`; при 401 хук виходить з акаунту й перекидає на `/login`.
 
**Стан і логіка:** власного стану немає (беремо `token` і `logout` з `AuthContext`, `navigate` з роутера), функція мемоізована через `useCallback`. Стани `loading`/`error` і відображення залишаються на сторінках, а вхід і реєстрація живуть в `AuthContext`.
