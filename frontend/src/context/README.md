# `AuthContext`: Tech Doc
 
> Ретроспективний опис: так я описав би цей модуль за підходом design-first.
 
**Що:** зберігає користувача й JWT, дає `login`, `register`, `logout` через хук `useAuth`.
 
**Стан:** `user` і `token` у `useState`, початкові значення беруться з `localStorage`, тому сесія переживає перезавантаження.
 
**Логіка:** `ProtectedRoute` перевіряє наявність користувача й роль (це лише зручність інтерфейсу), а справжню перевірку ролі робить сервер за підписаним токеном.
