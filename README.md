Це Single Page Application (SPA) аналог YouTube з клієнт-серверною архітектурою, реалізований у форматі монорепозиторію. Клієнтська частина побудована на базі React 18+, TypeScript, Redux Toolkit, React Query (TanStack Query), Axios, React Router та Tailwind CSS із застосуванням інструменту збірки Vite. Серверна частина реалізована на Node.js з використанням фреймворку Express, пакета pg для роботи з базою даних, а також бібліотек bcryptjs та jsonwebtoken для забезпечення безпеки. Як СУБД використовується реляційна база даних PostgreSQL, розгорнута на хмарній платформі Supabase Cloud з підключенням через функцію Connection Pooling на порту 6543. Локальне оточення розробки повністю ізольовано та контейнеризовано за допомогою Docker та Docker Compose.

Функціонал додатка охоплює систему реєстрації та авторизації користувачів на базі JWT-токенів із захистом приватних сторінок через Protected Routes на фронтенді, а також рольову модель доступу (RBAC) для розділення прав користувачів на рівні мідлварів Express (user та admin). Для адміністраторів інтегровано інтерфейс панелі керування (Admin Panel Layout), що дозволяє виконувати повний цикл CRUD-операцій (додавання, редагування, видалення) над метаданими відео в базі даних. Користувачам доступний динамічний пошук відео за назвою за допомогою SQL-оператора ILIKE, а також автоматична фіксація історії переглядів з унікальним обмеженням дублікатів записів у СУБД.

Деплой проєкту виконано на платформі Vercel, де фронтенд та бекенд розгорнуті як два окремі сервіси в межах одного репозиторію. Конфігурація сервера (backend/vercel.json) перенаправляє всі HTTP-запити на головну Serverless-функцію index.js за допомогою рантайму @vercel/node. Налаштування клієнтської частини (frontend/vercel.json) реалізує rewrite-правила, які перенаправляють запити на index.html для запобігання помилок 404 Not Found при прямому переході за SPA-маршрутами. Для стабільної роботи в production-середовищі в налаштуваннях Pool активовано SSL-шифрування (ssl: { rejectUnauthorized: false }), змінні оточення в панелі Vercel продубльовані для типів Production та Preview, а системна змінна VITE_API_URL вказана без символу слеша в кінці домену.
